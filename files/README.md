\## Project Overview



This website is an emotion check-in space. It is designed to help users gently notice, explore, locate, sit with, and remember their feelings. The website includes a homepage, an emotional palette, a body awareness screen, a gentle guidance flow, a memory page, an FAQ page, an information page, and an about page.



\## File Structure



\- `index.html` — homepage

\- `emotion\_checkin.html` — main emotional check-in flow

\- `memory.html` — saved emotional moments

\- `faq.html` — frequently asked questions

\- `information.html` — information about the website

\- `about.html` — design background and inspiration

\- `css/style.css` — main CSS file

\- `js/script.js` — main JavaScript file

\- `images/` — image and icon assets

\- `files/README.md` — references and acknowledgement information
